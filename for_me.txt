HOW TO ADD A NEW BLOG POST
==========================

Step 1: Write the post
----------------------
Create a new markdown file in _posts/ following the existing naming convention:

    _posts/YYYY-MM-DD-Your-Post-Title.md

Add the front matter at the top:

    ---
    title: "Your Post Title"
    date: YYYY-MM-DD
    categories: [Bioinformatics]
    tags: [Tutorial]
    ---

    Your post content here...

Categories you've used so far:
  - Bioinformatics
  - Bioinformatics Tooling
  - Bioinformatics Musings

Tags you've used so far:
  - Learning
  - Tutorial
  - Single Cell Omics


Step 2: Push the post to GitHub
-------------------------------
Commit and push so Jekyll builds the post page:

    git add _posts/YYYY-MM-DD-Your-Post-Title.md
    git commit -m "Add new blog post: Your Post Title"
    git push

Your post will be live at:
    https://mikemartinez99.github.io/posts/Your-Post-Title/


Step 3: Add the post to the portfolio homepage
----------------------------------------------
Open new-index.html (or index.html if you've renamed it) and find the
BLOG_POSTS array near the bottom of the file in the <script> section.

Add a new entry to the TOP of the array:

    const BLOG_POSTS = [
      {
        title: "Your Post Title",
        date: "YYYY-MM-DD",
        category: "Bioinformatics",
        tags: ["Tutorial"],
        desc: "A short 1-2 sentence description of the post.",
        url: "https://mikemartinez99.github.io/posts/Your-Post-Title/"
      },
      // ... existing posts below ...
    ];

The JavaScript automatically:
  - Sorts posts by date (newest first)
  - Updates the post count in the header
  - Generates filter buttons from all unique tags
  - Shows only 6 posts, with a "See older posts" link when there are more


Step 4 (optional): Add the post to the network visualization
------------------------------------------------------------
In the same script section, find the "posts" array inside the NETWORK VIZ
block and add a new entry:

    const posts = [
      { id: 'your-id', type: 'post', title: 'Short Title', year: 2026, cat: 'bioinformatics' },
      // ... existing posts ...
    ];

Then add links to connect it to other posts in the "links" array:

    const links = [
      { source: 'your-id', target: 'some-other-post-id' },
      // ... existing links ...
    ];

Category keys for the network (cat field):
  - bioinformatics
  - bioinformatics-tooling
  - bioinformatics-musings


DEPLOYING THE PORTFOLIO
=======================
To make the portfolio your homepage, rename new-index.html to index.html.
Jekyll will still build all your _posts/ into individual pages.
Links to blog posts on social media will NOT break.
